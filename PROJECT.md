# KT Public School — Flask Web Application

## 1. Project Overview

**KT Public School** is a public-facing school website built with Flask. It provides information about the school, displays notices and announcements, showcases a photo gallery, and accepts contact and admission inquiries.

### Scope (v1)

- Public website with server-rendered HTML pages
- Dynamic content: notices, gallery images, inquiry submissions
- PostgreSQL database for persistent storage
- Responsive design using Bootstrap 5

### Out of Scope (v1)

- Admin dashboard / CMS
- User authentication
- Fee management, attendance, student records
- Email notifications (forms save to database only)

## 4. Pages and Routes

| Route | Page | Data Source |
|-------|------|-------------|
| `/` | Home — hero, highlights, latest notices | DB + static |
| `/about` | About school, mission, principal message | Static |
| `/admissions` | Admission process, criteria, inquiry form | Static + DB form |
| `/notices` | List of school notices/announcements | DB (`Notice`) |
| `/notices/<id>` | Single notice detail | DB (`Notice`) |
| `/gallery` | Photo gallery grid | DB (`GalleryImage`) |
| `/contact` | Contact form + school address | Static + DB form |

## 5. Database Schema

### Notice

| Column | Type | Notes |
|--------|------|-------|
| id | Integer | Primary key |
| title | String(200) | Notice heading |
| body | Text | Full notice content |
| published_at | DateTime | Display date |
| is_published | Boolean | Visibility flag |
| created_at | DateTime | Record creation timestamp |

### GalleryImage

| Column | Type | Notes |
|--------|------|-------|
| id | Integer | Primary key |
| title | String(200) | Image title |
| image_path | String(500) | Path under `static/` |
| caption | String(500) | Optional description |
| uploaded_at | DateTime | Upload timestamp |
| is_active | Boolean | Visibility flag |

### Inquiry

| Column | Type | Notes |
|--------|------|-------|
| id | Integer | Primary key |
| name | String(100) | Submitter name |
| email | String(120) | Submitter email |
| phone | String(20) | Optional phone number |
| message | Text | Inquiry message |
| inquiry_type | String(20) | `contact` or `admission` |
| created_at | DateTime | Submission timestamp |

## 6. Environment Setup

### Prerequisites

- Python 3.12 or later
- PostgreSQL 16+ installed and running
- A PostgreSQL database named `kt_public_school`

### Create the Database

```sql
CREATE DATABASE kt_public_school;
```

### Virtual Environment

```powershell
cd "D:\KT public school"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Environment Variables

Copy `.env.example` to `.env` and update values:

```
DATABASE_URL=postgresql://user:password@localhost:5432/kt_public_school
SECRET_KEY=your-secret-key-here
FLASK_ENV=development
```

### Database Migrations

```powershell
flask db init          # First time only
flask db migrate -m "Initial migration"
flask db upgrade
```

### Run the Application

```powershell
python run.py
```

Visit `http://127.0.0.1:5000` in your browser.

## 7. Development Workflow

1. Activate the virtual environment
2. Make code changes in `app/`
3. If models change, run `flask db migrate` and `flask db upgrade`
4. Test locally with `python run.py`
5. Commit changes to version control

### Adding a New Page

1. Create a route in the appropriate blueprint under `app/routes/`
2. Create a Jinja2 template under `app/templates/`
3. Add a navigation link in `base.html`

### Adding a New Model

1. Define the model in `app/models/`
2. Import it in `app/models/__init__.py`
3. Run `flask db migrate -m "description"` and `flask db upgrade`
